## Tại sao repo này vẫn tồn tại

Đổi tên repo trên GitHub redirect *repo URL* nhưng **không** redirect *GitHub Pages URL* —
`https://quocdaijr.github.io/trungso/` sẽ trả 404. Repo này giữ URL Pages cũ sống bằng một
trang chuyển hướng.

Đánh đổi: vì một repo tên `trungso` lại tồn tại, GitHub **không còn** redirect
`github.com/quocdaijr/trungso` sang tên mới nữa. Nên nếu bạn `git clone` địa chỉ cũ, bạn sẽ
lấy đúng repo một-file này. Clone địa chỉ mới:

```sh
git clone git@github.com:quocdaijr/tientrivutru.git
```
